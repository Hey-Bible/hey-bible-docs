# Introduction

Welcome to **Hey Bible** - a free and easy to use Bible app, and the one-stop
gateway for giving AI agents access to the Bible. Whatever you're building, there's
a door that fits: an [Agent Skill](/developers/agent-skill), an
[MCP server](/developers/mcp-server), a [CLI](/developers/cli), a typed
[Node.js client](/developers/nodejs-client), and the [REST API](/api) underneath
it all.

![Hey Bible Banner](img/banner.png)

## Getting Started

With Hey Bible you can search for verses, save your favorites, add notes, and create beautiful, unique images of your favorite Bible verses to share with friends.

### App

Hey Bible is available on the web, iOS, and Android. Create an account using your email, or sign in with Apple or Google.

Once you're in the app, type a verse reference like "John 3:16" or "Matthew 18:3-4". You can tag and favorite verses, add notes, and generate images with just a few taps.

### API

Hey Bible provides a REST API for programmatic access to your saved verses, notes, and images. Generate an API key from your account settings to get started.

- [Generating API Keys](/developers/generating-api-keys) - How to create and manage API keys
- [Node.js Client](/developers/nodejs-client) - Official Node.js SDK
- [CLI](/developers/cli) - Look up Scripture from the terminal, scripts, and agents
- [API Reference](/api) - Full OpenAPI documentation

Give AI agents access to the Bible. Connect MCP-native assistants like Claude Desktop with the Model Context Protocol, or install the Agent Skill for OpenClaw-compatible agents.
