# MCP Server

The Hey Bible MCP server lets AI assistants like Claude Desktop look up Scripture and access your Hey Bible data — verses, favorites, notes, images, chats, and tags — directly from your conversations. It can also make a new verse picture with the `generate_image` tool, which spends your account's credits.

[![npm version](https://img.shields.io/npm/v/@hey-bible/mcp.svg)](https://www.npmjs.com/package/@hey-bible/mcp)

## What is MCP?

[Model Context Protocol (MCP)](https://modelcontextprotocol.io) is an open standard that allows AI assistants to connect to external data sources and tools. The Hey Bible MCP server exposes your Hey Bible data as tools that Claude can use to answer questions about your saved verses and notes.

## Installation

```bash
npm install -g @hey-bible/mcp
```

## Usage with Claude Desktop

Add the following to your Claude Desktop configuration file:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

```json
{
  "mcpServers": {
    "hey-bible": {
      "command": "npx",
      "args": ["-y", "@hey-bible/mcp"],
      "env": {
        "HEY_BIBLE_API_KEY": "your_api_key_here"
      }
    }
  }
}
```

Then restart Claude Desktop. You should see Hey Bible listed in the connectors menu.

## Environment Variables

| Variable | Description |
|----------|-------------|
| `HEY_BIBLE_API_KEY` | Required. Your API key, from Account > API Keys in Hey Bible. |
| `HEY_BIBLE_API_URL` | Optional. Override the API base URL (default: `https://api.heybible.app`), for example to run against a local stack. The [CLI](./cli.mdx) reads the same variable. |

To use a different API, add `HEY_BIBLE_API_URL` next to the key in the `env` block of your configuration.

## Available Tools

### search_verses

Look up Bible verses by book and chapter. Saves the result to your account. If `start_verse` and `end_verse` are omitted, returns the full chapter.

| Parameter | Type | Description |
|-----------|------|-------------|
| `book` | `string` | Required. Book name (e.g. "John", "Genesis", "1 Corinthians") |
| `chapter` | `number` | Required. Chapter number |
| `start_verse` | `number` | Optional. Starting verse number |
| `end_verse` | `number` | Optional. Ending verse number |
| `bible_id` | `string` | Optional. Translation ID (defaults to ESV) |

### get_bibles

List the available Bible translations (id, name, abbreviation, source). Takes no parameters.

### get_books

List the 66 books of the Bible with their 3-letter codes and chapter counts. Takes no parameters.

### get_favorites

Retrieve your favorited verses with their notes, images, conversations, and tags.

| Parameter | Type | Description |
|-----------|------|-------------|
| `tag` | `string` | Optional. Filter favorites by tag name |
| `limit` | `number` | Optional. Number of favorites to return (1-100) |
| `offset` | `number` | Optional. Number of favorites to skip for pagination |

### get_notes

Retrieve your notes associated with Bible verses.

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | `number` | Optional. Specific note ID to retrieve |
| `limit` | `number` | Optional. Number of notes to return (1-100) |
| `offset` | `number` | Optional. Number of notes to skip for pagination |

### get_images

Retrieve AI-generated images associated with your verses.

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | `number` | Optional. Specific image ID (returns signed URL with 24hr expiry) |
| `limit` | `number` | Optional. Number of images to return (1-100) |
| `offset` | `number` | Optional. Number of images to skip for pagination |

### generate_image

Draw a new picture for a verse and save it to your account, the same way the app does.

:::warning This tool spends credits
Each call takes credits from your Hey Bible account. The cost depends on the image model. Claude Desktop and many other MCP clients ask you before running a tool, so you can approve or decline each picture. If drawing fails after the credits are taken, they are refunded.
:::

Name the verse with `verse_id`, or with `book` and `chapter`.

| Parameter | Type | Description |
|-----------|------|-------------|
| `verse_id` | `number` | Optional. ID of a verse already saved to your account. When set, the book, chapter, verse and translation fields are ignored. |
| `book` | `string` | Book name (e.g. "Isaiah"). Required with `chapter` when `verse_id` is not set. |
| `chapter` | `number` | Chapter number. Required with `book` when `verse_id` is not set. |
| `start_verse` | `number` | Optional. First verse of the passage |
| `end_verse` | `number` | Optional. Last verse of the passage (defaults to `start_verse`) |
| `bible_id` | `string` | Optional. Translation ID. Use `get_bibles` to list them. |
| `theme` | `string` | Optional. `hey_bible` (default), `animals`, `celestial`, `custom`, `fantasy`, `flowers`, `landscape`, `literal`, `medieval`, `minimalist`, `stained_glass` or `watercolor` |
| `theme_content` | `string` | What to draw. Required when `theme` is `custom`. |
| `size` | `string` | Optional. `portrait` (9:16), `square` (1:1, default) or `landscape` (16:9) |
| `model` | `string` | Optional. Image model ID. Models cost different numbers of credits. |
| `quote` | `string` | Optional. Text printed on the picture (defaults to the verse text). At most 40 words for square and 70 for portrait or landscape. |
| `source` | `string` | Optional. Citation printed under the quote (defaults to the verse reference) |
| `copyright` | `string` | Optional. Copyright line. Ignored when the translation has its own. |

The tool returns the new image's id, a link to the image that works for 24 hours, and the credits it cost:

```json
{
  "image_id": 1234,
  "signed_url": "https://...",
  "credits_charged": 4,
  "image": {
    "id": 1234,
    "quote": "But those who wait for Yahweh will renew their strength. They will mount up with wings like eagles. They will run, and not be weary. They will walk, and not faint.",
    "source": "Isaiah 40:31 (WEB)",
    "size": "square"
  }
}
```

If `signed_url` is `null`, the picture was still made and saved. Fetch it with `get_images` and the id instead of generating it again.

If the API turns the request down, the tool returns an error with the API's message. A 400 means the input was wrong (for example a custom theme with no `theme_content`), and no credits were spent. A 402 means your account does not have enough credits for the chosen model.

### get_chats

Retrieve your chat conversations with verse context. If `id` is provided, returns a single chat with its messages.

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | `string` | Optional. Specific chat ID (UUID) to retrieve with messages |
| `limit` | `number` | Optional. Number of chats to return (1-100) |
| `offset` | `number` | Optional. Number of chats to skip for pagination |

### get_tags

List all the tags you've defined. Tags can be used to filter favorites. Takes no parameters.

## Example Prompts

Once configured, you can ask Claude things like:

- "What does John 3:16 say?"
- "Read me Psalm 23 in the KJV"
- "Show me my favorite verses tagged 'faith'"
- "What notes have I written recently?"
- "Make me a picture of Isaiah 40:31 in the WEB"
- "Make a watercolor landscape picture of Psalm 23:1 in the KJV"

## Troubleshooting

### Server not appearing in Claude Desktop

1. Verify your `claude_desktop_config.json` syntax is valid JSON
2. Ensure your API key is correct
3. Fully quit and restart Claude Desktop (not just close the window)

### Tools returning errors

1. Check that your API key is valid and not expired
2. Verify you have saved verses/notes/images in your Hey Bible account
3. If `generate_image` says the account is out of credits, add credits in the Hey Bible app and try again

### View server logs

On macOS, check the logs at:
```
~/Library/Logs/Claude/mcp-server-hey-bible.log
```
